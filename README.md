# Scientific Calculator — CodeAlpha Internship

A professional and responsive Scientific Calculator developed as part of the **CodeAlpha Frontend Development Internship — Task 2**.

## 🚀 Project Overview

This project is an interactive calculator built using **HTML, CSS, and JavaScript**. It supports basic arithmetic operations along with several scientific calculation features.

The calculator is designed with a clean, modern, and responsive user interface.

## ✨ Features

* Basic arithmetic operations
* Addition, subtraction, multiplication and division
* Parentheses support
* Power calculation
* Square calculation
* Square root
* Sin, Cos and Tan functions
* Logarithm and Natural Logarithm
* Pi (π) and Euler's number (e)
* Percentage calculation
* Factorial calculation
* DEG / RAD mode
* Delete (DEL) button
* All Clear (AC) button
* Keyboard support
* Error handling
* Responsive design
* Modern professional UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the project using **Live Server**.
5. The Scientific Calculator will open in your browser.
